# 📈 Stock Analysis and Prediction App

An AI/ML-based stock analysis application developed using Python and Streamlit. This project analyzes historical stock market data and predicts stock prices using LSTM deep learning.

## Features
- Stock Details & Historical Data Analysis
- Technical Indicators (RSI, MACD, SMA, EMA)
- Stock Price Prediction using LSTM
- Sector-wise Analysis
- Portfolio Management

## Technologies Used
- Python
- Streamlit
- TensorFlow / Keras
- Pandas, NumPy
- MySQL
- yfinance

## Installation

```bash
git clone https://github.com/vivekkathiriya/Predict-Stock-Price.git
cd Predict-Stock-Price
pip install -r requirements.txt
streamlit run app.py
```
